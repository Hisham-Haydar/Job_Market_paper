# JMP LOC4 Ruling v1 — Path B with Mandatory First Robustness

**Decision-maker:** ChatGPT JMP Deputy Programme Director  
**Status:** Binding before the welfare mission  
**Ruling:** PATH B

## 1. Decision

Proceed with the certified Phase-5 baseline for the first money-metric welfare
and inequality-decomposition prototype.

Do not delay the baseline welfare calculation until a LOC4 four-density model
has been estimated.

The LOC4 four-density specification is nevertheless pre-registered as the
**first mandatory wage-density robustness axis**. It must be completed before
the paper freezes its preferred quantitative decomposition magnitudes.

## 2. Economic rationale

The accepted baseline already establishes:

- a strongly identified opportunity/access block;
- precise hours and occupation-access parameters;
- a confirmatory regional/access rejection concentrated in GSUR;
- stable model-based and robust test verdicts.

The open LOC4 issue concerns whether occupation-specific wage dispersion changes
the welfare functional materially. It is not currently evidence that the
certified baseline is invalid.

Requiring LOC4 before any welfare prototype would postpone the paper's central
question without evidence that occupation-specific dispersion is first-order.
Ignoring LOC4 entirely would be inconsistent with the paper's emphasis on
opportunity-sensitive job packages.

Path B therefore separates:

1. baseline welfare feasibility and economic learning now;
2. mandatory wage-density robustness before final quantitative claims.

## 3. Frozen baseline

The first welfare prototype uses exactly the certified baseline:

- accepted sample;
- accepted preference parameters;
- accepted access/opportunity parameters;
- accepted common wage-dispersion structure;
- accepted job universe and budget mapping;
- accepted welfare metric and decomposition architecture.

No parameter is re-estimated inside the welfare mission.

## 4. LOC4 robustness contract

The first robustness after a successful baseline welfare prototype is the
project's already-defined LOC4 four-density variant.

The robustness mission must:

- use the existing LOC4 grouping definition;
- change only the pre-registered wage-density component;
- preserve the sample, utility specification, access index, tax-benefit mapping,
  welfare metric, inequality index, and decomposition rule;
- document whether mean and/or dispersion changes are introduced;
- prevent double counting between occupation-access coefficients and wage-density
  shifts;
- compare the same headline welfare and decomposition outputs.

Do not add sex-specific occupation densities, industry, external regional
covariates, or alternative grouping searches in the first LOC4 robustness.

## 5. Quantitative materiality rule

The LOC4 variant is considered materially different if any one occurs:

1. opportunity-attributable inequality share changes by at least 2 percentage
   points;
2. welfare Gini changes by at least 0.005;
3. mean or median money-metric welfare changes by at least 1 percent;
4. the sign or ordering of a headline decomposition component changes;
5. the paper's qualitative conclusion about the importance of opportunity
   heterogeneity changes.

If none occurs, retain the certified baseline as the preferred specification and
report LOC4 as robustness.

If any occurs, the preferred specification must be reconsidered before final
paper-facing quantitative claims.

## 6. Sequencing

1. M07: inference integration and welfare-input handoff.
2. M08 baseline: welfare and decomposition prototype under the certified model.
3. First robustness mission: LOC4 four-density variant.
4. Only after that robustness: freeze preferred quantitative welfare results.

M06 industry `lindi` and external regional covariates remain deferred.

## 7. Status classification

- **Central now:** M07 and the baseline welfare prototype.
- **Mandatory before final quantitative claims:** LOC4 four-density robustness.
- **Useful later:** parsimonious two-group LOC4 comparison if the four-density
  variant materially changes the results.
- **Not worth doing now:** broad occupation-group searches, sex-specific density
  proliferation, industry enrichment, or external-regional-covariate expansion.
