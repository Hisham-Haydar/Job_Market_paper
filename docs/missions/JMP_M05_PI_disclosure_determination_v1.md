# JMP-M05 PI Disclosure Determination v1

**Principal investigator:** Hisham Haydar  
**Mission:** JMP-M05 / JMP-M05B  
**Status:** Project-governance determination pending any later documented licence clearance

Household-level score arrays and row-level score renderings derived from the
French EU-SILC/EUROMOD microdata must not be committed or pushed to a public or
shared Git repository and must not be included in a public replication package.

The authoritative `.npy` score artifact may be retained only in a durable,
access-controlled, immutable restricted store. The manifest must record its
custody locator, SHA-256, byte size, shape, dtype, layout, row fingerprint,
column fingerprint, disclosure class, retention responsibility, and authorised
retrieval route.

Non-disclosive aggregate summaries, covariance matrices, parameter tables,
tests, hashes, fingerprints, and metadata may be committed, subject to the same
microdata disclosure review.

This is a conservative research-workflow rule and not a legal interpretation
of Eurostat or EUROMOD licence terms. A later written licence determination may
supersede the custody route without reopening the Phase-5 statistical design.
